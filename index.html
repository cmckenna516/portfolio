The Tools I Actually Use

These aren't tools I've tried once. This is my working stack — the tools I reach for daily to build, automate, and operate. My honest take on each.

🧠
Claude (Full Suite)
Primary AI

My daily driver for everything. I build Skills (automations), use Cowork mode for complex tasks, and have it connected to my calendar and email. Most of the builds in this portfolio started here.

💬
ChatGPT
Research & Ideation

Go-to for quick ideation, drafts, and broad research. Memory is genuinely useful. I bounce between ChatGPT and Claude depending on the task — they have different strengths.

⚡
Cursor
Code Editor

AI-native code editor. I'm not a developer by trade but Cursor lets me build real things. Write a description of what you want, get working code. The gap between idea and built has never been smaller.

🔁
n8n
Workflow Automation

Open-source automation that connects any system. I use it for multi-step workflows that run in the background — more powerful and flexible than anything else in its class.

🚀
Replit
Rapid Prototyping

Browser-based coding environment. Perfect for spinning up a prototype fast without worrying about setup. I use it to turn ideas into working demos in hours, not weeks.

🌊
Parabola
Data Automation

No-code data pipeline tool. Built complex flows at work connecting multiple data sources, transforming and routing data to the right places. Incredibly powerful for ops-heavy workflows.

🔗
Make.com
App Automation

Cross-app automation with a strong visual builder. More flexible than Zapier at the same price point. I use it when I need to connect consumer apps quickly.

📓
NotebookLM
Research Synthesis

Google's research tool for uploading documents and having AI synthesize across them. Excellent for turning a pile of PDFs or notes into a knowledge base you can query.

💎
Gemini
Multimodal AI

Google's AI with deep Workspace integration. Useful when everything already lives in Drive, Docs, and Gmail — it just works in that ecosystem.

🍌
Nano Banana
Generative Assets

Generative asset creation for visual content and creative AI work. Useful for producing content assets quickly without a design team in the loop.
