The Tools I Actually Use

These aren't tools I've tried once. This is my working stack — the tools I reach for daily to build, automate, and operate. My honest take on each.

🧠
Claude
Primary AI

My primary system for building, automation, and execution. I use Skills for repeatable workflows, Cowork mode for complex tasks, and integrate it with calendar and email. Most projects in this portfolio originate here.

💬
ChatGPT
Research & Ideation

Used for ideation, drafting, and broad research tasks. Memory improves continuity across projects, and it complements other AI systems with different strengths. Also used for image generation, creative assets, and custom GPT workflows like Media Assistant.

⚡
Cursor
Code Editor

AI-native code editor that enables rapid software development without formal engineering training. Converts natural language into working code and exposes file-level changes for transparency. Supports embedded AI workflows such as Claude Code for tighter control.

🔁
n8n
Workflow Automation

Open-source automation platform for building multi-step workflows across systems. Handles background processes with high flexibility and control. Used for complex automations beyond typical no-code tools.

🚀
Replit
Rapid Prototyping

Browser-based development environment that removes setup overhead. Enables fast iteration from idea to working application. Used to build internal tools and prototypes with full-stack functionality.

🌊
Parabola
Data Automation

No-code data pipeline tool for aggregating and transforming datasets. Combines multiple sources into structured outputs for downstream use. Supports building clean, centralized data systems without manual processing.

🔗
Make.com
App Automation

Visual automation platform for connecting applications and standardizing workflows. Offers greater flexibility than comparable tools at similar cost. Used to schedule and run reliable cross-system processes.

📓
NotebookLM
Research Synthesis

Document-based query system that returns source-grounded answers. Enables fast retrieval of specific information across large document sets. Reduces manual searching and avoids unsupported outputs.

💎
Gemini
Multimodal AI

Google AI integrated directly into Workspace tools. Enables interaction within Docs, Drive, and Gmail without context switching. Supports multimodal tasks across text and images.

🍌
Nano Banana
Generative Assets

Image generation tool optimized for speed and output quality. Produces visual assets without requiring design overhead. Handles rapid iteration for creative workflows.

What I'm Building Next

These are the ideas getting real time and real development effort. Each one is something I'd personally use — because that's the only products worth building.

01 · Health & Fitness
Fit in a Pinch
Daily Workout Coach

A voice-first fitness app that has a short conversation with you each day to figure out the optimal workout, then logs it and tracks your progress over time.

  • Voice-based onboarding — height, history, injuries, goals
  • Daily check-in: time available, location, soreness level
  • Curated workout library with AI-matched suggestions
  • Progress logging + integration with WHOOP, Apple Health
  • Smart reminders based on your actual schedule
02 · Consumer · Parenting
Dad Support GPT
AI Companion for Fathers

An AI companion for dads at every stage of fatherhood — grounded in parenting literature, learning your situation, and always ready to answer the question you're too embarrassed to Google.

  • Understands your timeline — due date, ages, circumstances
  • Grounded in popular parenting books and expert guidance
  • Proactively tells you what's coming in the next stage
  • Remembers what you've shared — gets smarter over time
  • Extensible to any life stage or support use case
03 · Career & Self-Discovery
TurasAI
AI Skill Discovery

An AI-guided skill discovery platform. It learns about you through conversation, generates hypotheses about where you may have real talent or potential, then assigns small experiments to test them — and scores your attempts with visible reasoning. The more you use it, the sharper it gets.

  • Conversational onboarding surfaces interests, energy patterns, and problem style
  • Generates skill hypotheses — not generic personality labels
  • Assigns small, low-cost experiments matched to your potential strengths
  • Scores attempts with a transparent rubric and plain-language feedback
  • Dashboard tracks signals over time and suggests what to try next
04 · B2B · People Ops
PeopleOS
Company Operating System

A unified internal platform that replaces the patchwork of tools most companies run on — intranet, project tracker, recognition, prompt library, and knowledge base in one place, connected to your existing stack via API.

  • Single source of truth for company knowledge and announcements
  • Built-in AI prompt library tailored to each team's workflows
  • Recognition and visibility tools that actually get used
  • SSO + role-based access — fits any org structure
  • API-connected to HRIS, Slack, and project management tools
